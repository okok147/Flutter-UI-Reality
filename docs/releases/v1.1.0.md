# Flutter UI Reality v1.1.0 — release candidate

This is a prepared release note, not evidence that a release has been published. Publish only after the revival pull request is merged and CI succeeds on the release commit.

## Highlights

- Revives active maintenance with clear supported and legacy scopes.
- Modernizes Gardener for Flutter 3.44 / Dart 3.12 with current Android, iOS, and web scaffolding.
- Replaces obsolete packages and hard-coded result cards with Flutter-native, data-driven components.
- Adds responsive behavior, accessibility semantics, and meaningful widget tests.
- Adds CI, Dependabot, licensing boundaries, security reporting, contribution guidance, and issue/PR templates.
- Documents historical asset provenance limits rather than applying an over-broad license claim.

## Verified checks required for publication

```sh
cd gardener_01
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build web --release
```

The release should state which platform builds were actually performed. At preparation time, Android and iOS builds were not available in the maintenance environment.
